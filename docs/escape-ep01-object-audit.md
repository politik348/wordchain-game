# 《모여 방탈출》 EP.01 완성 일러스트 오브젝트 감사표

> 2026-11-21 기준 · EP.01 v3.6 · 실제 게임 소스의 오브젝트 ID와 완성된 4개 일러스트(1200×650)를 대조하여 작성.

## 설계 및 검증 원칙

- **탁자 한 개로 뭉뚱그리지 않는다.** 책·서류·펜·종·천구의·서랍·선반처럼 플레이어가 독립된 사물로 보는 부분을 우선한다.
- 조사 점과 히트박스는 실제 손으로 만지는 부위(손잡이·종·건반·책·바퀴·꽃)에 둔다. 축소 시 조밀한 부분은 `detail` 히트박스(데스크톱 33px / 터치 38px)를 사용한다.
- **핵심과 낚시에 동일한 작은 점 표시**를 사용하며, 마우스 호버만으로 정답을 구분할 수 없게 한다.
- 첫 관찰은 무료. 각 심화 행동별 예상 소요 시간을 +5초/+10초/+15초로 구분해 즉시 게임 타이머에 더한다(실제 대기 없음). 이전 세이브의 이미 가산된 시간은 유지한다.
- 일러스트에 그려져 있지 않은 방 출입구나 미로 위치는 점을 임의 배치하지 않고 상단 이동 UI·대화 카드를 이용한다.
- 색유리 장난과 종 연주는 **선택형**이며 필수 인장·문 해금과 무관하다. 완료해도 필수 스토리 진행을 바꾸지 않는다.

## 그림에서 직접 확인한 대표적 부분

- **현관 오른쪽 접수대:** 종, 초대장/종이, 작은 책, 펜, 황동 천구의, 앞면 장식, 뒤쪽 푸른 문 명판.
- **현관 달 그림·벽장식:** 초승달 액자, 태피스트리의 고양이 문장, 네 개의 둥근 유리, 큰 문 문고리, 문 상단 장식.
- **현관 왼쪽 작은 탁자:** 꽃병, 아래 서랍의 손잡이, 아래 선반, 바닥 등불, 벽등, 왼쪽 문 명패·손잡이.
- **서재:** 집필대 위 원고·펜·조명·잔·책, 등받이 의자와 서랍, 책장과 사다리, 작은 시계·지구본·피아노 악보와 건반.
- **온실:** 찻잔·찻상 등잔, 꽃과 천장 덩굴, 작은 화분 행렬, 분수·조각상, 유리병·물뿌리개, 돔 꽃 유리.
- **시계탑:** 바닥 책더미·탁자 종이·찻잔·등잔, 큰 톱니바퀴 둘, 작은 동물 장식, 난간·창문·계단·시계.

# 사전 자료 출처

추가하는 공식 사전 데이터는 국립국어원 표준국어대사전 또는 우리말샘에서 사용자가 직접 다운로드한 것을 가정합니다. 실제 배포 시 사용한 사전 종류, 다운로드 날짜, 라이선스를 정확히 표시하세요.

- 출처: 국립국어원 《표준국어대사전》 https://kdict.korean.go.kr/standard/main/main.do
- 데이터 이용 조건: CC BY-SA 2.0 대한민국 (세부 정책·예외 확인 필요) https://creativecommons.org/licenses/by-sa/2.0/kr/
- 변경 내용(변환기): 표제어 정규화, 2~24글자 순한글 표기, 중복 제거, 명사 필터 적용. 예문/뜻풀이/멀티미디어 제외.

실제 원본 ZIP을 아직 받지 않았기 때문에 이 프로젝트의 `data/dictionary.json`은 현재 포함되어 있지 않습니다. 변환을 실행해야 생성됩니다. 다른 데이터 원본을 사용할 경우 이 파일의 출처 고지를 변경하세요.

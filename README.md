# 모여게임즈 — 7종 실시간 웹게임

한국어 웹게임 포털 [드립대학게임즈](https://dripp.kro.kr/)의 공개적으로 설명된 게임 목록·규칙을 참고하여 **처음부터 독립적으로 작성한** 프로젝트입니다. 원본 서비스의 소스 코드·이미지·상표를 복사하거나 서버에 연결하지 않았으며, 외관/게임 룰이 완전히 동일하지는 않습니다.

## 구현된 게임

| 게임 | 인원 | 주요 기능 |
| --- | --- | --- |
| 가면단 (마피아) | 4~12명 | 마피아·경찰·의사·시민, 낮 토론/투표, 밤 행동, 승리 판정 |
| 오목 | 2명 | 15×15 대국, 승리 판정, **간소화된** 직선 쌍삼 검사, AI 연습 |
| 윷놀이 | 2~4명 | 주사위형 윷 던지기, 지름길, 말 잡기·업기, 네 말 완주. **전통 규칙 간소화** |
| 낙서왕 | 2~8명 | 화가/제시어 배정, 동기화 캔버스, 정답 채팅·득점, 라운드 |
| 도깨비 종 | 2~4명 | 자동 카드 공개, 종 치기, 짝·도깨비 규칙, 점수 |
| 라이어 게임 | 3~8명 | 비밀 역할/주제/제시어, 설명, 투표, 최후 추리 |
| 끝말잇기 | 2~10명 | 서버 단어 판정, 턴 타이머, 목숨, 점수/미션, AI 연습 |

> **정확한 한계**: 끝말잇기는 700여 개의 수작업 구성 단어 목록으로만 판정합니다. 표준국어대사전 전체가 아닙니다. 오목 금수/윷놀이는 간소화된 규칙입니다. 별도 회원가입·영구 전적·관전/재접속 동기화의 장기간 보장은 구현되지 않았습니다. 프로덕션에서는 영속 DB·다중 인스턴스 세션 스토어·악용 방지/레이트 리밋을 추가하는 것이 좋습니다.

## 로컬에서 실행하기

**Node.js 20 이상** 필요. 외부 라이브러리를 설치할 필요가 없습니다.

```bash
npm start
```

브라우저에서 **http://localhost:3000/** 접속. 친구와 테스트하려면 같은 주소를 서로 다른 브라우저/기기에서 열고 방을 생성한 후 코드를 공유하세요. 로컬 네트워크에서 사용하려면 서버 컴퓨터의 LAN IP와 포트 3000에 접근할 수 있어야 합니다.

```bash
npm test
```

자동 테스트는 방 생성·입장·준비·승리·비밀 정보 보호 등 주요 경로를 점검합니다.

## 인터넷에 배포하기: GitHub + Render

1. GitHub에서 새 저장소를 만듭니다. 이 폴더의 파일들을 올립니다.
2. Render 서비스(https://render.com/)에서 **New → Web Service → Git Provider**를 선택하고 저장소를 연결합니다.
3. `render.yaml` Blueprint로 만들거나 Node 서버를 직접 만들 때 **Build Command**를 `npm install`, **Start Command**를 `npm start`로 지정합니다.
4. 배포된 `https://...onrender.com` 주소를 친구에게 보내면 됩니다. 친구들도 동일한 Render 주소에 접속해야 실제 멀티플레이가 작동합니다.

Render 무료 플랜의 슬립·재시작은 게임방이 사라지는 원인이 될 수 있습니다. 안정적인 상시 서비스가 필요하면 유료 상시 호스팅과 데이터베이스를 사용하세요. 요금·플랜 정책은 Render 공식 사이트에서 확인하십시오.

### GitHub Pages와의 차이

GitHub Pages는 정적 파일만 배포하기 때문에 **실시간 방 생성 서버를 실행할 수 없습니다.** `public/`의 파일만 GitHub Pages에 올리면 메뉴 탐색과 AI 연습은 작동하지만, 인터넷 멀티플레이는 제공하지 않습니다. 온라인 대전까지 쓰려면 Node.js 서버 호스팅이 필요합니다.

## 폴더 구조

```text
moyeo-games/
├─ server.js           # 순수 Node HTTP + SSE 실시간 게임 서버
├─ data/words.js       # 내장 단어 및 제시어 목록
├─ public/
│  ├─ index.html       # SPA 진입점
│  ├─ styles.css       # 모바일 반응형 디자인
│  ├─ app.js           # 모든 화면과 게임 UI/AI
│  ├─ words.json       # 정적 AI 연습용 단어 목록
│  └─ favicon.svg
├─ test/games.test.mjs # 통합 테스트
├─ package.json
└─ render.yaml
```

## 대형 한국어 사전 추가하기 (새 기능)

이 버전에는 **전체 사전 ZIP을 명사 단어 목록으로 변환하는 도구**가 들어 있습니다. 기본 설치본은 700여 단어의 샘플 목록을 사용하며, 실제 공식 사전 전체는 프로젝트 ZIP에 아직 포함되어 있지 않습니다. 공식 파일을 다운로드한 뒤 변환해야 합니다.

### 추천 자료: 국립국어원 표준국어대사전

1. 국립국어원 표준국어대사전 https://kdict.korean.go.kr/standard/main/main.do 접속
2. 회원가입/로그인 후 `내 정보 관리 → 사전 내려받기 → 전체 내려받기`에서 **JSON 전체 데이터 ZIP**을 받습니다. 화면 구성이나 메뉴 위치는 변동될 수 있습니다.
3. ZIP을 **압축 해제하지 않아도 됩니다**. Windows 명령 프롬프트에서 프로젝트 폴더로 이동하고 다음을 실행합니다. 파이썬 3이 별도로 필요합니다.

   ```bat
   py tools\import_dictionary.py "C:\Users\사용자\Downloads\전체 내려받기_표준국어대사전_JSON_날짜.zip"
   ```

   macOS/Linux는 `python3 tools/import_dictionary.py "/경로/사전.zip"`으로 실행합니다.

4. 프로그램이 `data/dictionary.json`(실시간 멀티플레이 서버용)과 `public/words.json`(컴퓨터 연습용)을 **동시에 갱신**합니다. `npm start`로 서버를 재시작하고 GitHub/Render에도 변경된 파일을 올립니다. 단어 데이터가 커질 경우 브라우저의 최초 연습 모드 로딩 시간이 늘 수 있습니다.
5. `data/dictionary.json` 및 `public/words.json`은 함께 업로드해야 하며, 수정된 `server.js`/`public/app.js`도 기존 버전을 덮어써야 합니다.

기본 추출 규칙은 **명사, 한글 완성형 2~24글자, 표기상 중복 제거**입니다. 인명·지명·전문용어는 별도 자동 분류하지 않습니다. 모든 품사를 허용하려면 `--all-pos`를 추가합니다. 품사가 없는 단어 TXT/CSV는 `--allow-untagged`를 추가해야 하며, 이 경우 품사 검증은 수행되지 않습니다. 실제 추출 수는 공식 파일 버전과 단어 조건에 따라 다르므로 20만 개를 보장하지 않습니다.

ZIP 외에도 JSON/XML/CSV/TXT 파일 또는 폴더를 넣을 수 있습니다. CSV는 `word,pos` 또는 `단어,품사` 열을 지원합니다. 구조가 특이한 파일은 자동 추출이 불가능할 수 있습니다.

**컴퓨터 연습 모드 성능 개선:** 대형 사전에서 매 턴 전 단어를 반복 검색하지 않도록 시작 음절별 인덱스를 생성합니다. 단어 판정은 서버에서 Set 기반으로 처리합니다.

## 2026-11-20 사용자 제보 수정

- **입력 중 화면 초기화:** SSE 실시간 동기화가 진행 중인 답안/채팅/힌트 입력창과 한글 IME를 덮어쓰지 않도록 수정. 전송 성공 시에만 내용을 비웁니다.
- **오목 돌 불투명:** 이미 둔 돌을 감싼 비활성 버튼의 공통 `opacity: .48` 규칙을 오목에서 해제.
- **낙서왕 문제 표시:** 화가는 카드에 제시어를 크게 표시, 나머지 참가자는 정답을 숨기고 글자 수와 역할만 표시.
- **낙서왕 그리기 유지:** 그림이나 채팅이 실시간 전달될 때 `<canvas>`와 입력창을 삭제·재생성하지 않도록 변경. 150점 이상 긴 드래그는 구간별로 전송.

기존 게임 코드는 수정한 ZIP에 포함되어 있습니다. 수정본을 GitHub 저장소에 덮어쓰고 Render에서 기존처럼 자동 배포하면 새 코드가 반영됩니다. 브라우저 캐시가 남으면 강력 새로고침(Ctrl+Shift+R)해 주세요.

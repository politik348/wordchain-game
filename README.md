# 모여게임즈 — 확장 사전, 쿵쿵따, 미친 오목

국립국어원 사전을 활용하는 독립 구현 실시간 브라우저 게임 7종입니다. 원본 게임 사이트의 비공개 코드나 상표를 복제한 것은 아닙니다.

## 2026-11-20 업데이트

- **끝말잇기/쿵쿵따:** 국립국어원 표준국어대사전(2026-11-06) + 우리말샘(2026-11-04) 명사 표제어를 병합해 **437,875개**. 쿵쿵따는 정확히 3글자입니다. 다른 품사와 구·문장은 제외했습니다.
- **반복 제한(항상 적용):** 같은 플레이어가 한 대국에서 자신이 이미 사용했던 **끝글자로 또 끝내는** 단어를 제출할 수 없습니다. 같은 단어 자체도 재사용할 수 없습니다. 켜기/끄기 옵션은 없습니다.
- **한방단어:** 그 단어로 시작할 수 있는 미사용 사전 단어가 하나도 없는 경우 '한방단어!'를 띄우고 즉시 그 단어를 낸 플레이어가 승리합니다. 쿵쿵따는 정확히 3글자만 후속 후보로 봅니다. 두음법칙도 반영합니다.
- **시간 초과 힌트:** 끝말잇기에서 제한시간을 넘기면 해당 플레이어에게, 그 시점에 유효했던 대안 단어를 최대 3개 보여줍니다. 실제로 한 개도 없으면 없다고 알립니다.
- **제한시간:** 끝말잇기, 오목, 윷놀이, 낙서왕에 **15/30/45/60/90초** 선택지를 추가했습니다. 온라인에서는 방장이 대기실에서 선택하며 서버가 시간을 판정합니다. AI 연습은 게임 상세 페이지 설정을 사용합니다.
- **오목:** '정상 버전'은 일반 흑백돌, '미친 버전'은 사용자가 제공한 토끼(흑)와 앵새기(백) 프로필 이미지로 돌을 표시합니다. 승리 판정 및 AI 엔진은 동일합니다. 사진은 요청한 게임에만 사용합니다.
- **낙서왕:** 실시간 선 그리기/지우기/정답 채팅은 WebSocket으로 처리합니다.

설정은 **각 게임의 상세 페이지 → 게임 설정**에서 선택한 다음 `새 게임방 만들기` 또는 `컴퓨터와 연습하기`를 선택하면 적용됩니다. 멀티플레이 방장의 설정은 대기실에서도 수정할 수 있습니다. 새 게임을 시작해야 변경사항이 적용됩니다.

## 실행과 테스트

Node.js 20 이상이 필요합니다. 압축 파일을 해제한 후 프로젝트 최상위 폴더에서:

```bash
npm start
# 다른 터미널에서
npm test
```

브라우저: http://localhost:3000. 친구와 실시간 대전을 하려면 GitHub Pages만으로는 부족하며 **Node.js 서버**를 Render 같은 호스팅에 배포해야 합니다. GitHub `main`에 이 프로젝트 전체 파일을 업데이트하고 Render의 **Live 커밋 SHA**를 확인한 뒤, 강력 새로고침하세요.

## 데이터 정확성과 범위

- `data/dictionary.json` — 실시간 서버가 판정에 쓰는 표제어.
- `public/words.json` — 브라우저 AI 연습 모드가 쓰는 동일 표제어.
- `data/dictionary-stats.json` — 자료 날짜, 추출 기준 및 집계.
- `tools/import_urimal.py` — 원본 ZIP을 가공하는 재생성 도구.

사용자가 제공한 국립국어원 전체 JSON ZIP은 용량 때문에 프로젝트에 **포함하지 않았습니다.** 재생성 시 공식 원본 ZIP을 사용하세요. `import_urimal.py`는 기존 표준 사전 JSON을 읽고 우리말샘 명사만 추가하도록 설계되어 있습니다. 재생성을 반복해도 중복을 제거합니다.

우리말샘은 참여형 사전입니다. 명사 표제어 수록 자체가 실사용 빈도나 표준어 지위를 보증하지는 않습니다. 약 44만 단어의 일부는 방언/북한어/전문용어일 수 있습니다. 프로그램은 표제어만 사용하며 뜻풀이·예문·미디어를 배포하지 않습니다.

## 출처와 저작권

- 국립국어원 우리말샘: https://opendict.korean.go.kr/
- 국립국어원 표준국어대사전: https://kdict.korean.go.kr/standard/main/main.do
- 국립국어원 자료 저작권·이용 정책: https://www.korean.go.kr/front/nuri/pageView.do?mkn=3&page_id=P000508

사전 데이터와 가공물의 이용·재배포 조건은 국립국어원 관련 정책을 확인하여 준수해야 합니다. 오목의 캐릭터 이미지 두 장은 사용자가 직접 제공한 파일이며 본 프로젝트에만 넣었습니다.

## 현재 한계

- 오목 금수는 간소화되어 있으며 공식 렌주 규칙 전체를 구현하지 않았습니다. AI는 탐색형 알고리즘이지만 승리를 보장하지 않습니다.
- 마피아·라이어·도깨비 종에는 이번에 선택형 제한시간을 추가하지 않았습니다.
- 게임방과 점수는 메모리에 유지됩니다. Render 서버를 재시작하면 진행 중인 방은 사라집니다.
- 공개 서비스 운영에는 관리·보안·로그 및 과도한 요청 제한을 강화할 필요가 있습니다.

## GitHub 배포 최적화: 분할 압축 사전

GitHub 웹 업로드에서 기존 파일과 충돌하지 않도록, 437,875개 명사 표제어를 `public/dictionary/part-*.json.gz`로 분할했습니다. `public/words.json`은 이 파일들의 목록을 담는 매니페스트입니다. 서버는 시작 시 이를 병합하고, 브라우저는 컴퓨터 연습을 선택할 때 압축 해제하여 사용합니다. 오래된 브라우저에서는 `/api/dictionary`를 이용합니다. 기존 `data/dictionary.json`은 제거했습니다. 파일을 임의로 삭제하거나 일부만 업로드하면 사전이 불완전해집니다.
